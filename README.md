# 🏦 Loan Approval Prediction System

An AI-powered Loan Approval Prediction Web Application built using Machine Learning and Streamlit.

The application analyzes applicant details such as income, loan amount, CIBIL score, assets, education, employment status, and other financial parameters to predict whether a loan application is likely to be approved or rejected.

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-github-repository-url>
```

Move into the project directory:

```bash
cd AIML_PROJECT
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
